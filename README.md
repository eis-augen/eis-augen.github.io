# Portafolio — Hashlaay Alderweireld

Sitio para presentar trabajo ante empresas: proyectos reales, tecnologías y enlaces a código de muestra **sin datos sensibles**.

| Parte | Contenido |
|-------|-----------|
| `site/` | Web del portafolio (Astro) |
| `showcases/` | Copias sanitizadas de proyectos del Escritorio |
| `tools/sanitize-copy.ps1` | Regenerar copias sin tocar originales |

**Ver local:** `site/dist/index.html` tras `npm run build` en `site/`.  
**Publicar:** [PUBLICAR-GITHUB.md](PUBLICAR-GITHUB.md).
